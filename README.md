# COURTSIDE AI

A free-to-run basketball coaching strategy and analytics game.

## Vision
Make coaching decisions against distinctive AI opponents, explore shot-quality and lineup analytics, and see decisions play out in a fast-paced possession simulator. Built as a hobby project and portfolio demonstration of decision modeling and data visualization—not an NBA 2K clone.

## Status
Initial project setup. Gameplay source lives in feature branches until reviewed and merged.

## Data integrity
The first playable prototype uses clearly labeled **fictional demo players and simulated outcomes**. It does not present simulation formulas as trained machine learning or invent live NBA data. Future real-data integration will identify the source, update timestamp, and limitations.

## Cost
Runs in a browser with no accounts, API keys, backend, or paid services. Can be hosted on GitHub Pages.
